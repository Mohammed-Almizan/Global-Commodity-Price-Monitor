Global Commodity Price Monitor (Jan 2000–Oct 2026)
1. Project Overview
This project analyses historical global commodity price indices using monthly data published by the World Bank.
2. Business Objectives
•	Analyse long-term global commodity price trends.
•	Compare cumulative growth across commodity index groups.
•	Identify commodity groups with higher monthly volatility.
•	Examine annual performance and year-on-year changes.
3. Dataset
•	Source: World Bank Prospects Group
•	Dataset: Commodity Price Data (The Pink Sheet)
•	File: CMO-Historical-Data-Monthly.xlsx
•	Period analysed: January 2000 – October 2026
•	Frequency: Monthly
•	Coverage: 16 commodity index series
Official source: https://www.worldbank.org/en/research/commodity-markets
4. Tools Used
•	Google Sheets: Data cleaning, calculations, data analysis and dashboard creation.
•	Spreadsheet formulas: Missing-value checks, percentage changes, averages, volatility calculations and rankings.
•	Charts and conditional formatting: Visual analysis and dashboard presentation.
5. Analysis Performed
•	Inspected the source dataset and checked date coverage.
•	Identified missing values and error values.
•	Assessed data coverage across commodity index series.
•	Calculated monthly returns and volatility.
•	Calculated long-term growth between January 2000 and October 2026.
•	Compared annual commodity index performance.
•	Ranked commodity groups by growth and volatility.
•	Created an annual performance heatmap.
6. Key Findings
•	Commodity index series analysed: 16
•	Highest cumulative growth: Precious Metals 1,234.45%
•	Highest monthly volatility: Energy 8.49%
•	Total Index cumulative growth: 295.76%
7. Dashboard
The dashboard presents:
•	Commodity index growth comparison.
•	Annual commodity price index trends.
•	Monthly volatility comparison.
•	Annual commodity performance heatmap.
•	Key performance indicators.
